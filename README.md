# 셀러 계산기

구매대행·오픈마켓 셀러를 위한 무료 계산 도구 사이트입니다.
회원가입 없이 쓸 수 있고, **입력한 숫자는 서버로 전송되지 않습니다** — 모든 계산이 브라우저 안에서 끝납니다.

사이트: https://picksome.github.io

## 계산 방식

실제 셀러 운영에 쓰는 내부 도구(Picksome Ops Tool)의 계산 로직을 브라우저용으로 옮긴 것입니다.

```
마진 = 매출 - 원가 - 배송비 - 마켓수수료 - 광고비 - 반품비용 - 풀필먼트비 - 결제수수료 - 부가세
```

- **금액은 원 단위 정수로만 계산합니다.** 소수(float)를 쓰지 않아 반올림 오차가 쌓이지 않습니다.
- **"0원"과 "모름"을 구분합니다.** 빈칸은 0으로 계산하되, 무엇이 비어 있었는지 경고로 알려 줍니다.
- **수수료 3종을 지원합니다.** 정률(RATE) · 정액(FIXED) · 구간별(TIERED).
- **역산은 정액 수수료의 부가세 효과까지 보정합니다.** 구간별 수수료는 구간 안에 해가 있는지 검증하고, 없으면 답을 내지 않습니다.

> 마켓 수수료·결제 수수료·반품률 기본값은 공개된 수수료 구간의 **추정치**입니다.
> 실제 요율은 카테고리와 계약 조건에 따라 다르므로, 정확한 계산은 본인 요율로 바꿔 넣어야 합니다.

## 개발

Node.js 22 이상이 필요합니다.

```bash
npm install
npm run dev      # http://localhost:4321
npm test         # 계산 로직 테스트 (43개)
npm run build    # dist/ 에 정적 사이트 생성
```

## 구조

```
src/
  lib/
    calc.js       마진·역산 계산 (산식은 여기 한 곳에만 정의)
    money.js      정수 금액·비율 연산, 반올림
    presets.js    마켓·결제·반품률 기본값
    form.js       화면 입력 → 계산 입력 변환
    site.js       사이트 이름·연락처·도구 목록
  components/     입력 폼 조각, 후원 영역
  layouts/        공통 레이아웃
  pages/          페이지 (tools/ 아래가 도구)
tests/            계산 로직 테스트
```

도구를 추가하려면 `src/pages/tools/` 에 페이지 파일을 하나 넣고, `src/lib/site.js` 의 `TOOLS` 에 한 줄을 더하면 됩니다.

## 배포

`main` 브랜치에 push 하면 GitHub Actions 가 테스트 → 빌드 → GitHub Pages 배포까지 자동으로 진행합니다.
테스트가 실패하면 배포하지 않습니다.
